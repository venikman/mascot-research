#### M-1 “Internal Motivation” (good/useful_meme_001.md)
* **Inputs:** personal reflection log, course outcome statement.
* **Key steps:** (1) extract personal gain signals → (2) map to values matrix → (3) anchor motivation to self-benefit.
* **Outputs (Work):** TwoLaneCard with fields `context, role, method_description, work_ref, timestamp`.
* **Failure conditions:** external pressure detected or missing personal goal link.
* **Scenes/apps:** reflection dashboard, weekly review.
* **Captions:** "Find your why." / "Motivation lives inside." / "External push fades."
* **Voice lines:** "Look inward first." / "Anchor to purpose." / "Drive from within."

#### M-2 “Gradual Progress” (good/useful_meme_008.md)
* **Steps:** (1) split goal → milestones; (2) record small wins; (3) visualize trend.
* **Outputs:** EvidenceTicket anchored per week.
* **Gates:** missed entries > 2 weeks → gate block.
* **Scenes:** habit app, dashboard.
* **Captions:** "Small steps stack." / "Progress ≠ rush." / "Iterate calmly."
* **Voice lines:** "Record each step." / "Growth is accumulation." / "Keep momentum."

#### M-3 “Constructive Error Handling” (good/useful_meme_003.md)
* **Steps:** (1) state mistake plainly; (2) extract hypothesis; (3) re-run improved step.
* **Outputs:** BridgeChip linking error → fix.
* **Gates:** repeat error w/o bridge update → red gate.
* **Scenes:** retrospective, code review.
* **Captions:** "Error → bridge." / "Learn don’t loop." / "Test your explanation."
* **Voice lines:** "Turn fail to link." / "Bridge the gap." / "Revise and confirm."

#### M-4 “Systematic Practice” (good/useful_meme_009.md)
* **Steps:** (1) schedule slots; (2) perform; (3) mark completion.
* **Outputs:** BadgeStamp confirming habit.
* **Gates:** <70 % consistency → amber badge.
* **Scenes:** learning planner, study portal.
* **Captions:** "Repeat to retain." / "System beats mood." / "Practice is the plan."
* **Voice lines:** "Badge earned by routine." / "Clock the cycles." / "Keep rhythm."

#### M-5 “Self-Discipline” (good/useful_meme_002.md)
* **Inputs:** checklist, reflection prompt.
* **Steps:** (1) plan → (2) observe temptation → (3) log override act.
* **Outputs:** TwoBoxVerdict (impulse vs decision).
* **Gates:** missing log entry > 2 days → yellow warning.
* **Scenes:** morning routine app, focus session.
* **Captions:** "Discipline is freedom." / "Hold the line." / "Routine protects."
* **Voice lines:** "Stay on track." / "Log before leap." / "Keep your boundary."
